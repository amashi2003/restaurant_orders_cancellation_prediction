# Restaurant Order Cancellation Prediction System

A machine learning model that predicts restaurant order cancellations to help improve operational planning and reduce losses.

## Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Project Overview
Built a predictive ML model to forecast whether a restaurant order will be cancelled based on historical order data. The model helps restaurant management proactively identify high-risk orders and take preventive action.

## Features
- Data cleaning and preprocessing
- Exploratory data analysis (EDA)
- Feature engineering
- ML model training and evaluation
- Visualizations of key insights

## How to Run
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run the notebook: `jupyter notebook`
